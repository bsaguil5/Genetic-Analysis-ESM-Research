# Data Directory

This folder contains all datasets used for training, testing, and discovery.

## Key Files

### 1. The Source of Truth
*   **`raw_sources/labeled_sequences_original.csv`**: The **Master Aggregation** dataset.
    *   **Size**: Contains original sequences that are processed into the final 1,323-sequence training set
    *   **Origin**: Aggregates multiple sources:
        *   Original "Good Boys/Bad Boys" (Sugar/ABC Transporters).
        *   `NEW_expanded_by_brandon_2025` (Kinases/Phosphatases).
        *   **Additional Expansion**: Multiple runs of `expand_dataset_HIGH_CONFIDENCE.py` fetched distinct batches of SWEET/ABC/Aquaporins.
    *   **Usage**: The `clean_and_retrain.py` script reads THIS file as the starting point.

### 2. Component Sources (Archive/Context)
*   **`NEW_expanded_by_brandon_2025/`**: A "High Confidence" collection from Nov 20, 2025 (592 sequences).
    *   Contains specific subsets like `transporters_HIGH_CONFIDENCE.csv`.
    *   **Note**: This is a *subset/component* of the Master CSV. Don't use this for training unless you specifically want the smaller, older high-confidence set.

### 3. The Active Training Set
*   **`cleaned_labeled_sequences.csv`**: Generated by `clean_and_retrain.py`.
    *   **Size**: 1,323 sequences (verified count - production training set)
    *   **Composition**: 517 Transporters (Label 0), 806 Non-Transporters (Label 1)
    *   **Note**: Earlier manifest (Dec 22) reported 1,095 sequences before final cleaning added 228 sequences
    *   **Logic**: Starts with `labeled_sequences_original.csv`, but automatically flips proteins from Label 0→1 if the description contains:
        *   "Kinase", "Synthase", "Ribosomal", "Transferase", "Reductase", "Mutase"
        *   "Transcription", "Zinc Finger", "Regulator", "Factor", "Nuclear"
        *   "Ubiquitin", "Polymerase", "Nuclease", "Receptor"
    *   **Usage**: The model trains on THIS file, not the raw source.
    *   **Status**: Verified clean - zero violations (Dec 21, 2025)

### 4. Multi-Task Dataset (Experimental)
*   **`multitask_labeled_sequences.csv`**: Same sequences as cleaned dataset, with additional labels
    *   **Size**: 1,323 sequences
    *   **Additional Labels**:
        - Subfamily (ABC, SWEET, NRT, MATE, etc.) - 8 classes
        - Substrate (Sugar, Nitrogen, Metal, etc.) - 6 classes
        - TM Domain Count (regression target)
    *   **Generation**: Created by `prepare_multitask_data.py` via keyword matching
    *   **Issue**: 69.3% labeled as "Unknown" subfamily, causing spurious correlations
    *   **Status**: EXPERIMENTAL ONLY - do not use for production
    *   **See**: LOGS/12-24-to-28-2025_MULTITASK_EXPERIMENT.txt for why this failed

*   **`multitask_label_mappings.json`**: Class index mappings for multi-task labels

### 5. Discovery Results
*   **`sorghum_hypothetical_unknowns.csv`**: Raw proteins fetched from NCBI by `fetch_sorghum_data.py`.
*   **`sorghum_discovery_results.csv`**: The raw output of the model predictions on the above.
*   **`final_sorghum_candidates.csv`**: The filtered "Platinum" candidates (High confidence Transporters).

### 6. Validation & Testing
*   **`robustness_test.csv`**: A blind test dataset fetched live from NCBI by `verify_robustness.py`.
    *   **Current Composition**: 319 sequences (200 Transporters, 119 Kinases)
    *   **Purpose**: Blind validation on fresh data to verify the model isn't overfitting.
    *   **Safety**: These sequences are explicitly **filtered out** if they appear in the training set. They are NEVER trained on. This ensures the 96.55% accuracy is real generalization, not memorization.
    *   **Latest Results** (Dec 22, 2025):
        - Accuracy: 96.55%
        - F1 Score: 0.9558
        - Kinase Rejection: 100% (119/119)
        - Confusion Matrix: [[189, 11], [0, 119]]
    *   **Status**: Regenerated when you run the verification script.

## 🗑️ Legacy Data
Old datasets like `good_boys.csv` (Sugar Transporters) and `bad_boys.csv` (ABC Transporters) have been moved to `../archive_legacy_2025/` to avoid confusion. We now use a generalized "Transporter vs Non-Transporter" scheme.
